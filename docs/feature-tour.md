# LitBoard 功能导览

LitBoard 将文献收集、阅读、批注、检索和引用写作集中在本地桌面应用中。文献库保存在用户选择的数据目录；同步与 AI 调研功能按需配置。

## 从一篇文献开始

1. **收集文献**：导入 PDF、BibTeX、RIS、CSL-JSON 或 PDF 文件夹，也可通过向导导入本机 Zotero 文献库。Chrome / Edge 扩展可从受支持的学术网站保存文献记录。
2. **阅读原文**：在标签页中打开 PDF、EPUB 或网页快照。PDF 支持文档目录、正文检索和扫描页 OCR；EPUB 支持阅读位置与批注。
3. **记录证据**：在 PDF 中添加高亮、下划线和评论，将批注摘录到笔记。笔记保留来源链接，便于返回原文核对。
4. **重新查找**：检索文献元数据、笔记、批注及已建立索引的文档正文；组合条件后，可将查询保存为智能文件夹。
5. **用于写作**：在 Microsoft Word 中插入和更新 CSL 引文及参考文献表，或导出 BibTeX 供 LaTeX、Typst 使用。

## 主要功能

| 功能 | 具体用途 |
| --- | --- |
| 批量导入与去重 | 将 PDF 文件夹作为目录树导入，识别文献条目，并依据标识符和标题等信息检查重复项。 |
| PDF 与 EPUB 阅读 | 阅读、定位和批注原文；PDF 扫描页可使用 OCR 提取文字。 |
| 笔记与摘录 | 将批注整理为带来源的摘录，并从笔记返回对应文献。 |
| 跨内容检索 | 联合检索文献、笔记、批注和已索引正文，使用智能文件夹保存筛选条件。 |
| 引用写作 | 使用 CSL 样式处理 Word 文档中的引文和参考文献，或导出 BibTeX。 |
| 数据管理 | 在本地保存文献库与受管附件，创建快照，并可选择使用坚果云 WebDAV 同步。 |

## 可选的 AI 调研助手

调研助手使用与主文献库分开的调研库。输入研究问题或论文段落后，它可以检索本地文献及 OpenAlex、Semantic Scholar 等来源，将段落拆分为论点，并列出候选文献及摘要中的相关语句。对于已索引或可获取的正文，还可继续按页、按章节阅读，或查看引用关系。

候选文献与论点的关联需要根据原文判断；未找到依据的结果不等于论点已被证伪。将发现的文献或下载的 PDF 写入主文献库前，应用会请求用户确认并执行去重检查。

AI 模型服务端点、向量模型和访问凭据由用户配置。模型请求及在线检索会访问外部服务；不配置 AI 服务时，仍可使用手动文献检索。
