# 功能导览

安装与连接步骤见[项目说明](../README.zh-CN.md)。以下为五条常用流程。

## 文件夹导入

拖到侧栏目标文件夹，按目录结构导入并检查重复项；也可用菜单或文件夹右键导入。

![文件夹导入](assets/gif/文件夹导入.gif)

## 浏览器采集

开启顶栏「扩展」接收服务，用端口和令牌连接 Chrome / Edge 扩展，再从学术页面保存；字段取决于站点。

![浏览器采集](assets/gif/扩展插件.gif)

## PDF 辅助阅读

打开 PDF，在右侧 AI 面板提问；工具按需读取页面，视觉模型可查看图表。模型服务需配置，普通阅读不依赖 AI。

![PDF 辅助阅读](assets/gif/辅助阅读.gif)

## Word 引用

在 Word 写作面板选择 CSL 样式与文献，插入引文及参考文献表。需安装本机 Word；元数据改正后刷新引用。

![Word 引用](assets/gif/插入引文.gif)

## AI 调研与引文图

输入研究问题，查看检索、证据与引文网络；结果收藏到主库前须确认。

![AI 调研](assets/gif/AI调研.gif)

![单篇论文引文网络](assets/gif/单篇论文拉取引文网络.gif)
