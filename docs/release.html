选择适合你的版本

目前面向 Windows x64。安装版和便携版使用同一套文献功能；浏览器扩展需要与桌面应用配合。

本页暂不提供下载直链。请以正式发布渠道列出的文件名、版本号及 SHA-256 校验文件为准；不要使用旧版本页面上的哈希校验新构建。

安装版 推荐

适合日常使用。运行安装程序后，从开始菜单启动 LitBoard。

LitBoard-Setup-<版本>-x64.exe

便携版

无需运行安装程序，适合放在自选位置使用。个人文献数据仍存放在配置目录或你选择的数据目录。

LitBoard-Portable-<版本>-x64.exe

Chrome / Edge 扩展

从受支持的学术网页保存文献。解压后在浏览器开发者模式中加载，并连接 LitBoard 内的接收服务。

LitBoard-Extension-<版本>.zip

校验文件

包含同一次正式发布中各安装包与扩展包的 SHA-256 值。下载后请先核对，再运行程序。

SHA256SUMS.txt

一条完整的文献工作流

LitBoard 将正式文献库留在本机；同步和 AI 服务由你按需配置。

收集与迁移

导入 PDF、BibTeX、RIS、CSL-JSON、PDF 文件夹，或通过向导迁移本机 Zotero 资料库。

阅读与批注

用标签页阅读 PDF、EPUB 和网页快照；检索 PDF、识别扫描页，并把高亮和评论摘录进笔记。

检索与整理

跨元数据、笔记、批注及已索引正文检索；组合条件后保存智能文件夹。

引用与调研

向 Word 插入引文、刷新参考文献表；可选的 AI 调研助手使用独立调研库，写入正式库前需要确认。

AI 调研助手：从问题走到可核对的文献

例如粘贴引言中的一段论述，请助手逐条寻找依据；找到候选文献后，继续读原文、看引用关系，再决定哪些值得收入正式库。

发现与交叉查找

同时检索正式库、独立调研库和 OpenAlex、Semantic Scholar。可用关键词查明确术语，或用整段文字做语义检索；配置 Elsevier Key 后可使用 Scopus。

逐条核对论述

把段落拆成具体论点，列出候选文献及摘要中的证据句，并区分支持、部分相关和未找到依据。只命中相近标题不会被当作证实。

读正文，也看图表

按页或章节读取已索引的 PDF、EPUB；开放获取论文可临时提取全文。遇到公式、图表或扫描页，支持图像的模型可查看渲染页，并说明实际读过的范围。

顺着线索继续研究

从一篇文献扩展引用网络，查看相关工作。对话与工具过程可留存；收藏文献或将已下载 PDF 收入正式库前，先展示操作并请求确认。

AI 调研库与正式文献库分开保存。模型端点、向量模型与凭据由你配置；模型请求和联网检索会访问相应外部服务。不配置 AI 服务时，仍可使用手动文献检索。

安装后，从一篇文献开始

打包版无需另装 Node.js。Word 引文功能需要本机安装 Microsoft Word。

  1. 启动 LitBoard。运行安装版或便携版，选择适合自己的数据目录。
  2. 导入文献。拖入 PDF、BibTeX、RIS 或 CSL-JSON；从 Zotero 迁移可到“设置 → 集成与服务”。
  3. 阅读并留下线索。打开 PDF 或 EPUB，把重要批注摘录到笔记，再从笔记跳回原文。
  4. 设置快照。在“设置 → 数据与备份”选择快照目录，再开始积累重要资料。

校验与更新

发布包尚未做代码签名，Windows SmartScreen 可能显示“未知应用”。请先核对正式发布附带的 SHA-256。

Get-FileHash .\LitBoard-Setup-<版本>-x64.exe -Algorithm SHA256

将结果与同一次发布中的 SHA256SUMS.txt 对照。目前没有自动更新；安装新版前，建议先在“数据与备份”创建快照，然后覆盖安装。文献库、附件与设置按原数据目录保留。

默认数据位置为 %APPDATA%\LitBoard；同步需要你自己的坚果云 WebDAV 账号，AI 调研需要自行配置模型服务。
