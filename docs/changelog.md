# 更新日志

## 未发布 · 升级体验：后台预下载 + 一键安装

### 新功能

- 发现新版本后自动在后台下载安装包，经 SHA-256（同 Release 的 SHA256SUMS.txt）校验后缓存到配置目录 `update-cache/`；就绪后提醒，点「立即更新」直接拉起安装界面并退出应用，不再经浏览器选择下载目录。
- 缓存任何时刻只保留一份安装包：隔代升级时新包落盘旧包即删；新版安装完成后下次启动自动删除缓存；中断残片启动即清，存储占用不随发布次数增长。
- 设置页「检查更新」按钮跟随状态变化（检查中 / 下载进度 / 立即更新）；重启后已就绪的更新仍会提醒。
- 便携版同样预下载，点更新后在资源管理器中定位新文件，按提示替换即可。
- `update-cache` 登记为运行时缓存目录，数据目录迁移时不随库搬移、旧目录清扫时自动删除。

### 结构调整

- 更新判定扩展纯函数层（`js/update.js`：SHA256SUMS 解析、缓存清扫计划）；主进程新增 `electron/update-check.js` 状态机（依赖注入、纯 Node 可测）。
- IPC 更新通道拆分为 `electron/ipc/update.js` 域：`app:check-update` / `app:update-status` / `app:apply-update`；移除浏览器下载旧通道 `app:download-update`。

### 回归覆盖

- 新增状态机测试：预下载就绪、重启免重复下载、装完自动清缓存、隔代替换、校验失败不留残片、并发去重、便携版行为、未打包空转。
- 新增纯函数测试：版本比较、Release 判定（含伪造直链拒绝）、校验文件解析、清扫计划。

## 1.0.1 · 2026-09-30 · 检索、调研与 IPC 结构优化

维护版本，无破坏性变更；数据格式与同步协议未变，可直接覆盖升级。

### 性能

- 普通关键词检索新增按文献版本与笔记快照校验的缓存，避免列表筛选、键盘移动、分页等重复规范化标题、摘要、作者和笔记内容。
- AST 文本检索复用笔记投影缓存，减少重复对象复制和笔记拼接。
- `research:fetch-page` 从整库加载改为按主键读取单篇文献，降低调研工具对主进程消息泵的阻塞。
- 调研库批量写入时复用向量内容哈希查询语句，避免逐条重新编译相同 SQL。

### 结构整理

- 删除确认无调用方的引文网络社区配色函数及孤立配色数据。
- 删除 6 组无调用方的 IPC/preload 通道：备份保留数量、备份遗留文件扫描与清理、批注图片保存、导出目标路径选择、调研库 harness 导入。
- 保留仍承担持久化、同步、测试或兼容契约的导出函数和模块，避免误删有效接口。

### 回归覆盖

- 新增普通检索缓存的命中、失效、笔记变更、空值和对象替换测试。
- 新增网页快照单篇读取、墓碑文献、全文索引等待和分块续读测试。
- 新增向量查询批次预编译次数与精确失效测试。
- 本轮验证：`npm test` 通过 1062 项，`npm run lint` 通过，Electron 隔离冒烟通过。
