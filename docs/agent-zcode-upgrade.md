# 调研计划与参考文件

入口：`agentplan / agentcontext / agentfilecontext / agentdispatch` 及相关 IPC。通用执行契约见[调研助手](agent.md)。

## 文件

- 📎 或拖放将文件复制到会话附件；取消待发送引用不删除已保存附件。消息仅含文件标识，正文按需读取。
- 工具只访问当前会话登记且路径校验通过的附件；`list_session_files` 分页，`read_session_file` 续读，`search_session_file` 返回字面命中与字符偏移。
- 文本、代码、CSV/TSV、JSON/XML、BibTeX/RIS、PDF、DOCX/XLSX/PPTX 可提取；Office 仅取文字和已有单元格值。
- 单次 ≤10 文件；单文件 ≤20MiB，图片 ≤8MiB；提取 ≤100 万字符。PDF ≤400 页、每页 ≤20 万字符；Office 解压量有界且在 worker 运行。
- `render_session_pdf_pages` 每次 ≤3 个物理页，需要视觉模型。覆盖只记录实际返回范围，截断或完整性未知不标记通读。

## 计划、补充与续接

- `update_research_plan` 保存目标、稳定步骤 ID、依赖、工具证据及附件引用；依赖完成才能开始，完成须有成功执行依据。
- 编辑重发或分支截断恢复当时计划；旧完成声明标待核验，先检查已有收藏、下载和文件。
- 运行中补充要求先保存，工具批完成后消费；停止后保留，可清空，下次新问题排在旧队列后。
- 错误重试从当前模型请求续接，保留已提交结果；partial 调用标未执行，不自动执行。
- 最多并行 3 个明确的本地只读工具；联网发现、计划与写操作串行。每个结果经单一保存链独立提交。

## 上下文

- 按完整真人轮次压缩，保留最新问题与工具配对；原文留在会话文件，摘要可能丢细节。
- 摘要无节省或计划过期时保留原文，不在该轮重复付费摘要。微压缩只缩短请求视图中的旧工具正文。
- 当前占用计入系统提示、工具定义、推理与图片，并用服务商输入用量校准；图片每张 1600 tokens 为粗估。
- 系统提示、工具 schema 或最新问题本身过长仍可能超窗，需缩小输入或分段续读。

验证已有隔离会话与假模型用例；真实服务商长任务、复杂 Office/PDF 阅读质量仍待任务级验收。
