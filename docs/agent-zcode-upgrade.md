# AI 调研执行与参考文件

参考项目：[zai-org/ZCode](https://github.com/zai-org/ZCode)，复核版本 `29628c9acdb81b703bbd4080c207a0e7ce5e276e`。本次借鉴其会话 Todo、工具事件检查点、压缩前整理上下文的做法，接入 LitBoard 既有 `agentcore / agentloop / agenttools / agentcontext`；没有替换调研库或协议层。

具体参照 `apps/zcode-cli/packages/core/src/tool/handlers/todo.ts`、`compact/rounds.ts`、`compact/microcompact.ts`、`runtime/methods/compact-persistence.ts`，以及 `packages/ui/src/v4/composer/attachmentUpload.ts` 的上传事务和待发送交互。这里按文献调研的现有边界自行实现，未复制上游依赖或引入通用磁盘访问/命令执行工具。

输入区的 📎 可多选参考文件，也可拖入 AI 面板。上传只复制到会话附件；待发送文件可点击 × 取消本条引用，已保存附件继续保留。发送后模型通过 `read_session_file(file, fromChar)` 按需读取与续读，消息只含文件标识，文件正文不自动塞进每轮上下文。附件受会话登记与实际路径检查约束，模型无法用该工具读取任意本机路径。

支持文本、Markdown、代码、CSV/TSV、JSON/XML、BibTeX/RIS、PDF，以及 DOCX/XLSX/PPTX 中的文字和单元格已有值。Office 不还原排版、图表、批注或计算公式；旧版 DOC/XLS/PPT、压缩包、音视频等返回明确的不支持状态。单次最多 10 个文件，单文件 20 MiB，图片 8 MiB；文本提取最多 100 万字符。Office 提取在 worker 中运行，ZIP 条目与实际解压量有限额。PDF 最多前 400 页、每页 20 万字符；页码为物理页码，扫描件、公式、图表可能不能正确提取，不据此宣称通读。图片需要视觉模型，非视觉模型会提示切换。

多步骤调研可以用 `update_research_plan` 保存目标、步骤状态和证据/续读位置；输入区显示计划进度。计划来自成功的工具结果，编辑重发或分支截断后回到当时的计划，压缩不删除原始工具记录。未完成计划提供「继续任务」，由用户发起新轮，先核对已完成结果。每个工具结果单独等待落盘；中断后保留已提交结果，将未确认调用补为未知状态，不自动重复收藏、下载或写入。页面截图引用与其工具结果同一检查点保存。

上下文压缩按完整真人轮次进行，保留最近提问、工具配对和尾部上下文，摘要提示保留目标、证据、进度、待办与限制；手动压缩可以提前执行。摘要没有节省空间或计划在请求期间已过期时保留原文，该轮不反复付费摘要。摘要请求有输入与输出预算，普通请求预留输出空间；旧轮裁剪修复了重复扣除预算和把合成图片当作新轮的问题。摘要仍可能丢失细节，原文保留在会话文件中；单个过长最新轮不会强制摘要最新问题，仍可能超出模型窗口，需要缩小输入或明确续读。

单轮工具链也按剩余输入预算进行免费的微压缩：请求视图先缩短旧工具正文，尽量保留最近三条结果；仍超额时继续缩短正文，保留调用配对与明确的压缩标记。计划和真人问题不删，原始工具结果不改；预算只计算实际协议字段，不把展示工具卡中的正文副本重复计入。最新一轮即使超过消息条数上限，也不从中间剪掉用户问题。系统提示、工具 schema 或用户本身过长仍可能超过模型窗口。

验证使用隔离临时会话与假模型响应，不读取真实用户库，也不自动提交、发布或部署。真实服务商在线长任务与真实复杂 Office/PDF 的阅读质量仍需实际使用验证。


本轮按可靠性、上下文、参考文件、续接、计划与调度顺序补齐：检查点提交失败立即停轮，执行副作用前必须先保存。停止会按会话与轮次取消 PDF/网页下载，批量操作不再派发后续任务；已开始的原子文件或数据库提交可能已经成功，回执与未知状态如实保留，不能假定已经撤销。

底部现在显示“当前上下文占用”，累计计费用量仍内部保存。自动压缩使用服务商输入用量校准并加上后续请求增量，计入系统提示、工具定义、需要回放的推理与当前图片。图像 token 按每图 1600 粗估，具体模型分辨率规则不同，数值不是精确计费或上界。压缩后立即清旧校准、显示压缩前后占用；摘要仍使用本轮冻结模型。

`list_session_files` 可分页核对附件与实际阅读范围，`search_session_file` 给字面关键词片段和精确续读偏移；搜索扫描不代表读完。`render_session_pdf_pages` 在视觉模型下将上传 PDF 的最多 3 个物理页截图送入本轮，适合图表、公式和扫描页。本轮未新增通用 OCR 服务，文本提取截断或完整性未知时不会标记全文读完。

运行中输入“补充要求”后会先保存队列，在当前工具批完整结束后处理。停止后保留队列，可清空；下次新提问前先接入旧队列，新问题排在最后。错误卡重试从当前模型请求续接，保留已执行结果；partial 工具调用只补“未执行”，不自动执行。仅明确 HTTP 429/502/503/504 拒绝与 DNS/连接拒绝有限退避两次，尊重不超过 10 秒的 Retry-After；更长等待直接报错供稍后续接。有内容、推理或工具片段的中断不自动重发，避免重复计费。

计划步骤有稳定 id、依赖、成功工具证据和已登记附件引用；只有依赖完成才可开始，完成声明由程序验证执行依据存在。这不证明科研结论正确。旧计划的完成声明改为“待核验”，保留历史并要求先核对既有数据，防止重新收藏/下载。安全并行限 3 个明确的本地只读工具；联网发现、工具计划与写入保持串行屏障。结果每完成一个便通过单一保存链提交，不等待整批完成。
