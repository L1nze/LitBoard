# LitBoard · 发布与下载说明

LitBoard 是 Windows x64 上的本地优先文献工作台，支持文献导入、PDF / EPUB 阅读、批注与笔记、跨内容检索，以及 Microsoft Word 引用写作。WebDAV 同步和 AI 调研助手可按需启用。

> 当前文档不提供下载直链或固定版本号。正式发布时，请以同一次发布列出的安装包、扩展包和 SHA-256 校验文件为准。

## 选择版本

| 文件 | 用途 |
| --- | --- |
| `LitBoard-Setup-<版本>-x64.exe` | Windows 安装版，适合日常使用 |
| `LitBoard-Portable-<版本>-x64.exe` | 便携版，无需运行安装程序 |
| `LitBoard-Extension-<版本>.zip` | Chrome / Edge 文献收藏扩展，需解压后手动加载 |
| `SHA256SUMS.txt` | 核对同一次发布的文件是否完整 |

不要用旧版本发布页中的哈希核对新构建。下载后可在 PowerShell 中运行：

```powershell
Get-FileHash .\LitBoard-Setup-<版本>-x64.exe -Algorithm SHA256
```

## 可以完成的工作

- 导入 PDF、BibTeX、RIS、CSL-JSON、PDF 文件夹，或迁移本机 Zotero 资料库。
- 在标签页中阅读 PDF、EPUB 和网页快照；检索 PDF，识别扫描页，把批注摘录到笔记。
- 检索元数据、笔记、批注及已索引正文，组合条件并保存智能文件夹。
- 向 Microsoft Word 插入和刷新引文、参考文献表，或导出 BibTeX。

## AI 调研助手

把研究问题或一段论文草稿交给助手后，可以沿着一条可核对的路径继续：

1. **找文献**：检索正式库与独立调研库，从 OpenAlex、Semantic Scholar 发现新工作；配置 Elsevier Key 后可查 Scopus。关键词检索与段落语义检索可按问题选用。
2. **核对论述**：将段落拆为论点，逐条列出候选文献、摘要中的证据句及出处，区分支持、部分相关和未找到依据。
3. **读正文**：按页或章节读取已索引的 PDF、EPUB；可临时提取开放获取论文的全文文本。支持图像的模型还可查看公式、图表和扫描页的渲染图，并说明实际读过的范围。
4. **扩展与留存**：查看可交互的引用网络，保存对话与工具过程。收藏文献或将下载的 PDF 收入正式库前，先由用户确认并进行去重。

AI 调研库与正式文献库分开保存。模型端点、向量模型和凭据由用户自行配置；模型请求与在线检索会访问对应的外部服务。不配置 AI 服务仍可使用手动文献检索。

## 安装与更新

打包版无需另装 Node.js；直接使用 Word 引文功能需要本机安装 Microsoft Word。文献库、笔记和受管附件默认保存在 `%APPDATA%\LitBoard`，也可选择其他目录。

目前没有自动更新。下载新版覆盖安装前，建议先在“设置 → 数据与备份”创建快照。安装包尚未做代码签名，Windows SmartScreen 可能提示“未知应用”；运行前请对照发布的 SHA-256。

同步需要用户自己的坚果云 WebDAV 账号。AI 模型请求和在线检索使用用户配置的外部服务；这些功能未启用时，文献库仍可离线使用。
