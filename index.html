设置

本地数据位置

配置目录放应用设置与缓存、同步附件与批注图片；文献库目录放数据库、全文索引和备份。你在其他位置选择的 PDF 与附件不会移动。路径可直接输入或点「选择…」，目标须为空目录或当前目录；点「应用并重启」后 LitBoard 会重启并搬移数据，随后清空旧目录（只留一个定位文件记录新位置）。

会话记录（AI 助手）

会话目录保存对话、工具结果与生成文件，是长期成果：不随缓存清理；改位置后新会话落新目录，已有会话保留原处。

Zotero 文献库（可选，只读）

完整备份（自动轮换，含全部附件）

完整备份会保存文献库、全文索引和所有已关联的本地附件。设置目录后，LitBoard 在软件开启期间自动检查，距上次成功备份满 24 小时才会再次执行；内容没有变化时不会重复保存。

包含：文献库数据库、PDF / EPUB、补充材料、网页快照、笔记图片与批注截图。调研库仅附带身份核文件，不包含摘要等完整调研数据；从备份恢复时也不会自动恢复调研库。不包含 WebDAV / API 凭据及浏览器扩展令牌。默认保留最近 7 份。

调研库（AI 助手）

调研库保存检索发现的文献元数据（身份、摘要、引用关系），存储在配置目录 research/ 下，随数据目录迁移。

检索完成后会在后台为本批最多 25 篇文献补全摘要；点击「补全摘要」可为已有文献再补一批（每次最多 100 篇）。摘要来源：Crossref → Elsevier（遇到限流会暂停）。「文献库关联调研库」为文献库中的文献建立调研身份。

坚果云 WebDAV

「立即同步」先把当前设置落盘，再与坚果云双向核对一次：上传本地改动、取回云端较新的版本。

云端恢复与冲突对照

先只读检查云端版本。新设备可直接恢复已同步到 LitBoard 的文献与附件；已有本地数据时会生成逐字段对照，未解决冲突不会写回云端。
